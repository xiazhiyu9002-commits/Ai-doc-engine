# 二、离子式 / 电离式
### 1. 简单离子
- $\ce{H+}$、$\ce{OH-}$、$\ce{Na+}$、$\ce{K+}$、$\ce{Ca^2+}$
- $\ce{Cl-}$、$\ce{SO4^2-}$、$\ce{NO3-}$、$\ce{CO3^2-}$

### 2. 电离方程式
- $\ce{HCl = H+ + Cl-}$
- $\ce{H2SO4 = 2H+ + SO4^2-}$
- $\ce{CH3COOH <=> H+ + CH3COO-}$
- $\ce{NH3·H2O <=> NH4+ + OH-}$
- $\ce{H2O <=> H+ + OH-}$

### 3. 水解离子方程式
- $\ce{CH3COO- + H2O <=> CH3COOH + OH-}$
- $\ce{NH4+ + H2O <=> NH3·H2O + H+}$
- $\ce{Fe^3+ + 3H2O <=> Fe(OH)3 + 3H+}$

---

# 三、普通化学反应方程式
### 1. 化合
- $\ce{2H2 + O2 = 2H2O}$
- $\ce{CaO + H2O = Ca(OH)2}$

### 2. 分解
- $\ce{2KMnO4 ->[\Delta] K2MnO4 + MnO2 + O2 ^}$
- $\ce{2H2O2 ->[MnO2] 2H2O + O2 ^}$

### 3. 置换
- $\ce{Zn + 2HCl = ZnCl2 + H2 ^}$
- $\ce{Fe + CuSO4 = FeSO4 + Cu}$

### 4. 复分解
- $\ce{HCl + NaOH = NaCl + H2O}$
- $\ce{AgNO3 + NaCl = AgCl v + NaNO3}$
- $\ce{CaCO3 + 2HCl = CaCl2 + H2O + CO2 ^}$

# 四、热化学方程式
- $\ce{H2(g) + 1/2O2(g) = H2O(l)}\ \ \Delta H = -285.8\ \mathrm{kJ·mol^{-1}}$
- $\ce{C(s) + O2(g) = CO2(g)}\ \ \Delta H = -393.5\ \mathrm{kJ·mol^{-1}}$
- $\ce{N2(g) + 3H2(g) <=> 2NH3(g)}\ \ \Delta H < 0$

# 六、电化学
### 1. 电极反应
- 负极（Zn）：$\ce{Zn - 2e- = Zn^2+}$
- 正极（Cu）：$\ce{Cu^2+ + 2e- = Cu}$
- 电解水：
  阴极：$\ce{2H+ + 2e- = H2 ^}$
  阳极：$\ce{4OH- - 4e- = 2H2O + O2 ^}$

### 2. 电池总反应
- $\ce{Zn + Cu^2+ = Zn^2+ + Cu}$

### 3. 能斯特方程
\[
E = E^\circ - \frac{RT}{zF}\ln Q
\]

\[
E = E^\circ - \frac{0.0592}{z}\lg\frac{[\text{还原}]}{[\text{氧化}]}
\]

# 七、酸碱 & 缓冲溶液
- $\ce{pH = -lg[H+]}$
- $\ce{pOH = -lg[OH-]}$
- $\ce{pH + pOH = p}K_w$
- 亨德森-哈塞尔巴尔赫方程：
\[
\mathrm{pH} = \mathrm pK_a + \lg\frac{[\text{共轭碱}]}{[\text{弱酸}]}
\]

# 八、物理化学公式（核心）
### 热力学
- $dU = TdS - pdV$
- $dH = TdS + Vdp$
- $dA = -SdT - pdV$
- $dG = -SdT + Vdp$
- $\Delta G = \Delta H - T\Delta S$
- $\Delta_r G_m^\circ = -RT\ln K^\circ$

### 相平衡
- 克劳修斯-克拉佩龙：
\[
\ln\frac{p_2}{p_1} = -\frac{\Delta_{vap}H_m}{R}\left(\frac1{T_2}-\frac1{T_1}\right)
\]

### 动力学
- 一级反应：$\ln\frac{[A]_0}{[A]} = kt$
- 二级反应：$\frac1{[A]}-\frac1{[A]_0}=kt$
- 阿伦尼乌斯：$k = A\mathrm e^{-E_a/RT}$
- 米氏方程：$v = \frac{v_{\max}[S]}{K_M+[S]}$

# 九、结构化学 & 量子化学
- 定态薛定谔方程：$\hat H\psi=E\psi$
- 三维：
\[
\left(-\frac{\hbar^2}{2m}\nabla^2+V\right)\psi=E\psi
\]
- 氢原子能量：
\[
E_n = -\frac{me^4}{8\varepsilon_0^2h^2n^2}
\]
- 一维势箱：
\[
\psi_n(x)=\sqrt{\frac2l}\sin\frac{n\pi x}{l}
\]
